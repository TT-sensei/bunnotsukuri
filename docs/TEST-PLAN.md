# テスト計画

## 学習の流れ
- ホームから10のステージを始められる。
- それぞれの問題で答えをえらび、正解・もう一度の表示を確認できる。
- ヒントを見たあとも答えられる。
- 答えと説明を見た問題は、正解として記録されない。
- 最後の問題から結果画面へ進める。
- 結果画面から、もう一度・特訓・ホームへ進める。
- 答えを選ぶ前と、まちがえたあとに「この問題をとばす」で次の問題へ進める。
- とばした問題はふり返りに表示され、今回の正答率からは外れる。

## 答えの確認
- select/classify：登録したIDと合うと正解。
- pair/relation：二つの言葉と、つなぐ向きが合うと正解。
- strip：正しい言葉の組み合わせなら、順番に関係なく正解。
- repair：登録した正しい直し方をすべて受け入れる。
- reorder：登録されたどの正しい順番でも正解。
- `answerPatterns` に登録した別解も正答として受け入れ、すべての語句IDが問題の選択肢に存在する。
- compose：登録した条件を満たしたことを表示し、文全体の自然さを機械だけで決めない。

## 文法と読みやすさ
- 主語は「が」「は」だけで決めず、「も」などが付く場合も文の意味から考えられる。
- 「春には、花がさく」「この犬は、耳が大きい」のように、いつを表す言葉や話題と、じゅつ語につながる言葉を区別する。
- じゅつ語のなかまに、うごき・ようす・何か・ある/いることを表すものがある。
- くわしくする言葉が、名詞・じゅつ語・別のくわしくする言葉につながる例を確認する。
- 言葉が離れている問題でも、文の意味からつながりを考えられる。
- 子ども向け表示では「じゅつ語」「くわしくする言葉」を使い、難しい漢字はひらがなや読みがなで補う。
- 基本の問題は短くし、チャレンジでは文の長さや考えることを少しずつ増やす。
- 問題IDに重複がなく、選択肢の数と登録した答えが合っている。

## 保存
- リロード後も回答の記録と設定が残る。
- JSONを書き出せる。
- 書き出したJSONを読み込める。
- 正しくないJSONを読み込んでも、今ある記録が消えない。
- 記録を消す前に確認が出る。

## 画面
- 横幅375pxほどのスマートフォンで、横スクロールやボタンの重なりがない。
- タブレットとPCでも、問題文・操作・進み具合が見やすい。
- ボタンはタップで操作できる。
- 色だけで正解・不正解を伝えない。
- 動きを少なくする設定に対応する。
- キャラクター画像が出なくても学習を続けられる。
