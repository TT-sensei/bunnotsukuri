# ことばのつらなり｜TT-sensei

主語・述語・修飾語の役割を見つけるだけでなく、言葉どうしの関係を考え、分かりやすい文へ直す小学生向け国語学習アプリです。

公開先（GitHub Pagesを有効にした場合）： https://tt-sensei.github.io/bunnotsukuri/

## 学習内容

1. 主語を見つける
2. 述語を見つける
3. 主語と述語をつなぐ
4. 修飾語を見つける
5. 修飾語のかかる相手を見つける
6. 文の骨組みを取り出す
7. 述語の種類を分ける
8. 主語・述語のねじれを直す
9. 語順を工夫する
10. 自分で文を作る

## ファイル構成

- `index.html`：アプリの入口と読み込み順
- `css/styles.css`：色、レイアウト、タブレット・スマホ対応
- `js/data/questions.js`：学習ステージと問題データ。問題追加の主な編集場所
- `js/core/grading.js`：問題形式ごとの正答判定
- `js/core/storage.js`：学習記録の保存、書き出し、読み込み
- `js/core/analytics.js`：技能別の記録と練習提案
- `js/ui.js`：画面のHTML表示
- `js/app.js`：画面遷移、回答、学習進行
- `docs/SPECIFICATION.md`：設計・採点・記録仕様
- `docs/TEST-PLAN.md`：確認手順

HTML/CSS/JavaScriptのみで動作します。npm、ビルド、APIキー、外部データベースは必要ありません。

## 編集するとき

- 問題を増やす・直す：`js/data/questions.js`
- 正答判定を直す：`js/core/grading.js`
- 見た目を直す：`css/styles.css` と `js/ui.js`
- 学習記録や苦手分析を直す：`js/core/storage.js` と `js/core/analytics.js`
- 画面の進行を直す：`js/app.js`

問題データでは、語句のIDと正答を対応させます。複数の正解がある問題は `answer` に候補をすべて登録し、解説には正答になる理由を書きます。主語の省略や修飾関係が曖昧な文は、文脈を用意するか、問題として使わないでください。

## 保存とプライバシー

学習記録は利用中のブラウザの `localStorage` に保存されます。オンライン送信や外部APIへの送信は行いません。端末・ブラウザを変えると自動では引き継がれないため、必要に応じてJSONで書き出してください。共有端末では、利用後の記録管理に注意してください。
